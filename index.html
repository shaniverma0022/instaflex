How to Use

  1. Copy the Instagram Reel or video link.
  2. Paste it into the input box.
  3. Press Get Video.
  4. Choose Download Video or Download HD.

FAQ

Which videos can I download?

Videos from the Instagram account connected to this site, retrieved through Instagram's official API. Private content and other people's accounts are not available.

Is a watermark added?

No. The original file is passed through untouched, with no logo, text, intro or outro added. If the creator's video already has one, it stays as it is.

What is the difference between the two buttons?

Instagram's API provides one file per video, so both buttons give you the original upload. We never promise a quality the source doesn't offer.

The download failed. What now?

Press Retry. If the link has expired, press Get Video again.
